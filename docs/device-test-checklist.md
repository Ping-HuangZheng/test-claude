# 手機測試清單

雲端環境沒有模擬器也沒有實機，下面這些需要在手機上確認。打勾的方式：做完一項就在 `[ ]` 裡填 `x`。

## 安裝

- [ ] `adb install -r app-debug.apk`（或把 APK 傳到手機直接點開安裝）能裝起來
- [ ] App 名稱顯示「待機時鐘」，圖示是時鐘

## 錶面與手勢

- [ ] 打開後是全螢幕，Android 的狀態列和導覽列都隱藏
- [ ] 預設是數位錶面，時間正確
- [ ] 在中間往左滑 → 指針；再往左 → 翻頁；再往左 → 回到數位。往右滑反向
- [ ] 兩指縮放可以放大縮小；關掉 App 再開，大小還在；每個錶面各自記住
- [ ] 翻頁錶面：分鐘改變時有翻頁動畫
- [ ] 指針錶面：時針、分針位置正確

## 控制列

- [ ] 點一下畫面出現控制列；5 秒不動自動收起
- [ ] 控制列出現時再點一下空白處會收起
- [ ] 「‹」「›」切換錶面；「夜間模式」切換；「鬧鐘」「設定」打開對應頁面，返回鍵可回到時鐘

## 狀態列

- [ ] 左上日期正確（例如「11月11日 週三」）
- [ ] 右上電量正確；插上充電器後幾秒內變成「充電中」並出現閃電；拔掉後恢復

## 設定

- [ ] 時間格式：跟隨系統／12 小時（有「上午／下午」）／24 小時，切換後立刻生效
- [ ] 顯示秒數：數位、翻頁出現秒數，指針出現秒針
- [ ] 名言輪播可以關掉；開著時下方有一行名言，10 分鐘後換句

## 夜間模式、亮度、防烙印

- [ ] 夜間模式：字變暗紅色，畫面變得很暗
- [ ] 在畫面左側或右側上下滑：中間出現「亮度 xx%」，畫面亮度跟著變；放開 1 秒後提示消失
- [ ] 在畫面中間上下滑：亮度不變、錶面不變
- [ ] 白天、夜間的亮度分開記；設定頁可以「跟隨系統」「還原 5%」
- [ ] 系統的亮度設定沒有被改動（下拉通知列看亮度條）
- [ ] 開著放 10 分鐘以上：螢幕不會自己關掉；畫面位置會慢慢小幅移動

## 充電待機（螢幕保護程式）

- [ ] 設定頁的「開啟系統螢幕保護程式設定」能打開系統設定頁
- [ ] 在系統設定選「待機時鐘」、時機選「充電時」
- [ ] 充電中讓螢幕逾時關閉 → 自動出現時鐘，錶面、夜間模式、亮度和 App 一致
- [ ] 碰一下螢幕就結束螢幕保護程式

## 鬧鐘

- [ ] 鬧鐘頁：點時間可以改，改完自動開啟鬧鐘；Android 13 以上會詢問通知權限
- [ ] 「需要處理的權限」區塊沒有出現（或照提示處理完後消失）
- [ ] 「試響一次」：有鬧鈴聲＋震動，有「貪睡」「停止」可以按
- [ ] 時鐘畫面左上出現「鬧鐘 07:00」之類的提示；Android 狀態列出現鬧鐘圖示
- [ ] 設一個 2 分鐘後的鬧鐘，鎖定螢幕等它：會點亮螢幕並跳出響鈴畫面
- [ ] 手機正在使用時響：跳出可以操作的通知
- [ ] 按「貪睡 5 分鐘」：停止響，5 分鐘後再響，左上顯示「貪睡 hh:mm」
- [ ] 按「停止」：停止響；只響一次的鬧鐘會自動關閉，重複的會排到下一次
- [ ] 不理它：10 分鐘後自動停止
- [ ] 手機靜音模式下鬧鐘仍會響（走鬧鐘音量）
- [ ] 重開機後，鬧鐘頁的「下次響鈴」還在，時間到會響

## 已知限制

- 響鈴時如果把通知欄整個拉下來，Android 可能停止重複播放聲音（通知還在，點它可以打開響鈴畫面）。
- 有些廠牌的省電機制比較激進，建議把本 App 的電池設定改為「不受限制」。
- 有些廠牌拿掉了「螢幕保護程式」設定，那種手機無法用充電待機，只能手動開 App。
